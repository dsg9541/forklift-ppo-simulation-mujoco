# PPO 训练断点与续训

`train/` 下的训练脚本都包含 `CheckpointCallback`。默认每 1,000,000 步把模型保存到
脚本所在目录的 `train_model/`：

```text
<脚本名>_ckpt_<累计步数>steps_<批次标签>.zip
<脚本名>_latest.zip
<脚本名>_latest.json
<脚本名>_ckpt_interrupt_<批次标签>.zip
```

`latest.zip` 是标准 Stable-Baselines3 模型文件，可用于继续训练或直接加载评估。

## 命令行参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--total-steps` | 按脚本和历史记录决定 | 累计训练目标步数；续训时只补跑目标与当前步数的差值 |
| `--resume` | `auto` | `auto` 优先使用最新断点，其次加载 `--model` |
| `--resume ckpt` | - | 只使用 `train_model/` 中最新的本脚本断点 |
| `--resume none` | - | 从零开始训练 |
| `--resume PATH` | - | 从指定 `.zip` 模型或断点继续 |
| `--ckpt-interval` | `1000000` | 断点保存间隔 |
| `--n-envs` | `23` | 并行环境数 |
| `--xml` | `model/forklift_train.xml` | MuJoCo 训练场景 |
| `--model` | 因脚本而异 | 初始模型；同时作为正常训练结束时的保存路径 |
| `--lr` | 因脚本而异 | 覆盖本阶段的起始学习率 |

## 常用命令

需要先从项目根目录进入训练环境：

```powershell
cd D:\path\to\forklift-ppo-simulation-mujoco
```

从最新断点继续训练到累计 6,000,000 步：

```powershell
python train/ppo_3/train_mohu_12.py --resume ckpt --total-steps 6000000
```

从指定断点继续训练：

```powershell
python train/ppo_3/train_mohu_12.py `
  --resume train/ppo_3/train_model/train_mohu_12_latest.zip `
  --total-steps 8000000
```

从零开始训练 1,000,000 步：

```powershell
python train/ppo_3/train_mohu_12.py --resume none --total-steps 1000000
```

## 学习率续接

续训时默认读取断点处的学习率，再线性衰减到 `FINAL_LR`。若上一轮已经达到目标步数，
则视为新阶段，从脚本的 `INITIAL_LR` 重新开始衰减。也可以用 `--lr` 显式覆盖起始值。

## 注意

- `--total-steps` 是累计目标，不是本次新增步数。
- 训练正常结束时会保存到 `--model`，并在 `train_model/` 额外保存最终断点。
- 保存失败只打印警告，不会中断训练。
- 断点和 TensorBoard 日志默认被 `.gitignore` 排除。
